# 模型接入

本地 CLI 不直接调用模型。使用 Codex、Claude Code 或其他能读取 skill、读取文件并执行命令的 agent 即可；agent 读取 skill 后使用的是同一套本地 CLI 和规则。

模型 key 留在宿主的安全配置中，例如通过环境变量引用注入，不提交到 Git，也不要写进文件、命令参数、日志或报告。宿主配置若支持 `${ENV_VAR}` 形式的引用，应保持引用，不改为明文持久化。

报告由本地 JSON/Markdown 保存，不依赖任何云端报告存储，也不声称调用过第三方云服务。

若宿主对非只读的 MCP 提交工具（`tools/blind_submit_mcp.py`）要求较高执行级别，须同时保留精确的工具白名单和只读隔离；不要启用跳过权限检查的选项。
